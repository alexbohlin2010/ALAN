## Tier D: judgement calls, AI research, or hand-typed values (these are what we rebuild slowly and under human control)

| Item | Where | Issue |
|---|---|---|
| 50-city lamp/CCT research | `research_rows/*.json` → `alan_streetlight_cct_50cities.csv` | Values were researched by an LLM. Confidence is one label per **row**, not per value. Assumptions are labelled "documented". 7 of 13 "guess" rows were silently blanked. 12–14 cities were never researched. |
| City lamp mixes | `C` dict hard-coded in `build_csv.py` | Hand-entered, and inconsistent with the colour layer (Beijing 3000K/0.6 vs 4000K/0.5) |
| City colour compositions | `colour/city_colour_compositions.csv` | 23 of 43 rows inferred. The R5 "CCT prior" and R7 "back-cast" rules are really estimates. |
| Lamp class rules | `lamp_classes.py` regexes + CCT bins | Hand rules, not documented separately |
| Aurora fill | `tiler.py` | Pixels inside 7 hand-copied event boxes are **replaced** with 13-year medians, i.e. invented values |
| Tone curves | `tiler.py` (HI=8.3, γ 0.62), shader (1.2 / 2.2), `clean_render.py` amber ramp | Display choices. The value 8.3 isn't derived anywhere. The amber colour is invented and the page doesn't say so. |
| Globe colour | `colorize.py` | Lamp colour estimated per city, drawn as circles sized by HDNTL `litkm2`. Outside cities, a generic colour. |
| C1 geocoding | `resolve_c1_locations.py` | ~50 hand rewrites (e.g. "Piedmont" → Maryland). The "reviewed" statuses are assigned automatically. Institution addresses stand in for study sites. |
| C3A brightness | `prepare_c3a_migration.py` | Taken from the **red channel of the display tile ÷ 255**, not radiance. Missing tiles become 0 with no per-point flag. Uses 2024 tiles for 2016–20 tracking. |
| C3B constants | `prepare_c3b_radar.py` | Results from the paper typed in by hand with no page references. ALAN maximum 18.933 hard-coded. |
| Body clocks | `build_body_scene_asset.py` | "Zebra finch" is typed into the script. One cage's treatment is inferred without a per-row flag. |
| Unit mislabel | `index.html:923`, C1 | HDNTL (Black Marble) values are shown as "VIIRS nW/cm²/sr" next to VNL pixels. Different products. |
